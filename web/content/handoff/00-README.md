# PCI website builder handoff

Upload this folder, or paste `01-SITE-BRIEF.md` as the project brief.

Read in this order:

1. `01-SITE-BRIEF.md` — what the site is
2. `02-PAGES-AND-COPY.md` — page text
3. `03-DESIGN.md` — palette and type
4. `04-DO-NOT.md` — hard exclusions
5. `site-config.json` — structured nav, chapters, operations
6. `corpus/` — full live chapters, sub-chapters, and articles

Do not use retired material from any older PCI file if it conflicts with this folder.
